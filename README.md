# KARIYA Frontend

Frontend statis untuk company profile LPK KARIYA.

## Struktur
- index.html
- style.css

## Teknologi
- HTML5
- Bootstrap 5.3.3
- Bootstrap Icons
- CSS custom
- Google Fonts

## Menjalankan
Cukup buka `index.html` di browser.

Catatan:
Gambar saat ini memakai URL gambar publik sebagai placeholder. Untuk versi final, sebaiknya diganti dengan foto asli LPK, instruktur, peserta, fasilitas, dan alumni.
